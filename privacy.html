Privacy Policy – Tamjaibaan Autopost

Last updated: 3 November 2026

"Tamjaibaan Autopost" is a private, internal tool used only by the owner of the YouTube channels ตามใจบ้าน (@tamjaibaan) and Meora Pet Shop. It uploads short videos that the owner made and reviewed to the owner's own channels. It is not offered to, and cannot be used by, anyone else.

What the tool accesses

  • Through the YouTube API Services, with the owner's permission (Google OAuth), the tool uploads videos and sets their title, description and privacy status on the owner's own channels, and may post a comment on those videos.
  • It reads basic statistics (views, watch time) of the owner's own videos to compare which videos perform better.
  • It does not access, collect or store any data about viewers or other YouTube users.

How data is stored

  • The OAuth access/refresh tokens are stored only on the owner's personal computer and are never shared or uploaded anywhere.
  • Video statistics are stored in local files on the same computer for the owner's own analysis.
  • No data is sold, shared with third parties, or used for advertising.

Data retention and deletion

  • Statistics of the owner's own videos are kept only for the owner's analysis and are refreshed or deleted in line with the YouTube API Services Developer Policies.
  • The owner can delete all stored data at any time by deleting the local files and revoking access (below).

YouTube API Services

This tool uses YouTube API Services. By using it, the owner agrees to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Revoking access

Access can be revoked at any time from the Google Account security settings: https://myaccount.google.com/permissions. After revoking, the locally stored tokens stop working and are deleted.
